# 素材预览模块 — 设计文档

## 概述

在 Meta 自动化任务配置页面的素材配置模块下方，新增素材预览功能。用户配置完筛选条件后，点击「预览素材」按钮，在表单内展开预览区域，查看匹配的素材列表。纯查看模式，不改变现有提交流程。

## 触发方式

底部按钮区增加「预览素材」按钮，位于「取消」和「确定」之间：

```
[取消]  [预览素材]  [确定]
```

- 按钮样式：白色背景 + 蓝色边框 + 蓝色文字（与 `.drama-add-btn` 风格一致）
- 预览按钮与搜索按钮行为一致：素材数据筛选为「自定义」且未配置任何条件时禁用
- 点击展开/收起预览区域（toggle 行为）

## 展示位置

在素材配置模块（`#materialConditionItem` 等）下方、底部按钮区（`.form-footer`）上方，插入预览区域。

结构：
```
素材配置模块
  └── 素材创建时间 / 素材数据筛选 / ... / 广告数
预览区域（初始隐藏，点击预览后展开）
  └── 加载中 / 空结果 / 数据表格
底部按钮区
  └── 取消 / 预览素材 / 确定
```

## 数据列（9列）

| 列名 | 数据来源 | 说明 |
|------|----------|------|
| 素材名称 | mock | 素材文件名 |
| 剧本ID | mock | 如 L0001 |
| 剧本名称 | mock | 如 繁花 |
| 短剧 | mock | 短剧本地化名称 |
| 语言 | mock | 中文/英文/泰文等 |
| 消耗 | mock | 金额格式化 |
| DOROI | mock | 数值 |
| 达标率 | mock | 百分比 |
| 创建时间 | mock | YYYY-MM-DD 格式 |

无汇总统计行。表格底部显示「共 N 条，仅展示前 10 条」（如超过10条）。

## 三种状态

1. **加载中**：居中文字「正在查询匹配素材...」
2. **空结果**：居中文字「未找到匹配的素材，请调整筛选条件」
3. **有数据**：表格 + 底部计数

## 交互规则

- 预览区域 toggle：点击按钮展开，再次点击收起
- 修改素材条件（筛选类型切换、条件增删改、排序切换等）后，预览区自动清空并收起，需重新点击预览
- 修改已选短剧后同上
- 预览为纯查看，不改变取消/确定的原有行为
- 确定提交时，不携带预览数据（预览仅前端展示）

## 实现范围

- 修改 `index.html`：新增 CSS 样式 + HTML 结构 + JS 逻辑
- 数据全部 mock，无后端依赖
- 预览按钮禁用逻辑复用现有素材条件校验（`checkMaterialConditionRequired`）
